# Legacy token-audit Examples (Archived)

These directories and files are artifacts from the **token-audit** era, before the
project was renamed and rebuilt as **polish**. They are kept here for reference
only — they were generated by old scripts and workflows that no longer exist in
this repository.

What's here:

- `anthropic-url/` — audit artifacts from a live fetch of anthropic.com (URL scanning)
- `anthropic-local/` — audit artifacts from a local Anthropic design-system sample
- `noah-sample/` — audit artifacts from the Noah Mind project's `src/pages`
- `fetch-url.sh` — old helper that downloaded a URL's HTML + CSS for auditing
- `preview.html`, `preview-comparison.html` — static preview pages of the above

Notes:

- **URL scanning is not a current polish capability.** Polish scans local files;
  `fetch-url.sh` and the `anthropic-url` artifacts reflect the old workflow.
- The generated exports (`style-dictionary/`, `shadcn-theme.css`) and reports in
  these directories were produced by the old `token-audit` tool, not by the
  current `polish` CLI. Do not expect `polish` to regenerate them identically.
- To see the current, runnable pipeline, see [`../walkthrough/`](../walkthrough/README.md).
